# Multipliquendo ✖️
Un minijuego en donde tienes que multiplicar...

## Jugabilidad 🕹️
En este juego existen tres modos de juego, Facil, Normal y Dificil. Al iniciar se generara una multiplicacion aleatoria y tu con tu ingenio, lo tendras que resolver.
